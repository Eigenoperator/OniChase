# V3 PHASE 1 STATIONS

## Purpose

This document lists the first key station groups for `v3 phase 1`.

It is not meant to replace full line-level station inventories.
Its role is to define the first important station priorities for:

- geometry validation
- label ranking
- service-data validation
- future gameplay pilot selection

## Tier A: Must-Have Mega Hubs

These stations are non-negotiable in `v3 phase 1`.

- Tokyo
- Shinagawa
- Ueno
- Omiya
- Shinjuku
- Shibuya
- Ikebukuro
- Akihabara
- Yokohama
- Shin-Yokohama

## Tier B: Core JR Structure Stations

These stations define the inner Tokyo and near-Tokyo rail structure.

- Kanda
- Yurakucho
- Hamamatsucho
- Tamachi
- Osaki
- Ebisu
- Yoyogi
- Nippori
- Tabata
- Kawasaki
- Ofuna
- Chiba
- Nishi-Funabashi
- Maihama

## Tier C: Shinkansen / Intercity Anchors

These stations matter because they connect the nationwide intercity layer into the Tokyo-area map.

- Sendai
- Morioka
- Shin-Aomori
- Niigata
- Nagano
- Kanazawa
- Tsuruga
- Nagoya
- Kyoto
- Shin-Osaka

## Tier D: First Private-Rail Anchors

These should be prioritized once the first private-rail trunks enter the map.

- Jiyugaoka
- Musashi-Kosugi
- Futako-Tamagawa
- Shimokitazawa
- Chofu
- Keikyu-Kawasaki
- Yokohama (private-rail interchange treatment)
- Kitasenju
- Tokorozawa
- Keisei-Ueno

## Why These Station Groups Matter

They are the first stations that should be used to validate:

- real station placement
- station-group construction
- interchange relationships
- line overlap and label density
- future route-planning stress points

## What This File Does Not Mean

This file does **not** mean only these stations should appear in `v3 phase 1`.

If a line is included, the whole line still belongs to scope.
This station list only defines:

- major map priorities
- major data-validation checkpoints
- major gameplay-relevant transfer hubs

## Immediate Use

These station groups should be used first for:

1. label rank tuning
2. operator / interchange validation
3. service-data sanity checks
4. first future gameplay pilot slices on the enlarged map
