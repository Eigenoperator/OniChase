## Tokyo Tokaido Highlight

- Investigated why choosing `東海道線` at 東京 also lit `新川崎`, `武蔵小杉`, and `西大井`.
- Root cause: the MLIT/N02 physical map labels the Shinagawa-Tsurumi freight/品鶴線 infrastructure used by the Yokosuka Line as `東海道線`, and older v3 rematched Yokosuka/Sobu rapid trips also contributed broad station sets to the JR East `東海道線` route.
- Changed gameplay bundle station-set construction so traced cross-line trips no longer add every stop to their primary route.
- Added a UI highlight filter for JR East `東海道線` so route-stop halos only show the operating-route stations and exclude Yokosuka/Sobu rapid branch-only stations such as `新川崎`, `武蔵小杉`, `西大井`, `保土ヶ谷`, and `東戸塚`.
- Local Playwright check confirms those branch-only stations are present in the raw route set before filtering and absent from the highlighted set after filtering.

## Odakyu Hakone Direct Services

- Investigated missing Odakyu/Hakone-bound trains, especially Romancecar services from `新宿` to `箱根湯本`.
- Root cause: the Odakyu collector only seeded `小田急電鉄` N02 stations, so `小田急箱根` railway stops such as `箱根湯本`, `箱根板橋`, `風祭`, and `入生田` were excluded. A second parser bug only matched stop rows with station links, so terminal rows without `<a>` were also dropped.
- Updated `build_v3_odakyu_train_instances.py` to include `小田急箱根` `鉄道線` stations, parse terminal `<li>` rows without links, add the `00000828` Hakone Tozan color, and classify Romancecar service names as `特急`.
- Updated gameplay public service-name detection so `ホームウェイ` and the other Odakyu Romancecar names stay visible instead of falling back to `小田原線`.
- Rebuilt Odakyu, v3 unified trains, v3 Tokyo bundle, v4 rematched v3 trains, current trains, and gameplay timetable/map bundles.
- Verification: raw Odakyu now has 225 trains containing `箱根湯本`; v3 unified has 192 `箱根湯本` trains; v4 current has 300 `箱根湯本` trains; gameplay compact has 299 `箱根湯本` trips, with 16 `新宿 -> 箱根湯本` and 16 `箱根湯本 -> 新宿` direct compact trips.
