# DIARY - 2026-05-12

今天主要把 v4 的 selected-train / selected-route 高亮视觉收口。之前为了让选中车次更显眼，高亮层和底层线路的颜色、线宽、描边存在差异；Scorp 明确要求“高亮显示要和线路完全相同”，所以把高亮层改成沿用真实线路的颜色、几何和线宽比例，不再使用白色 casing 或自创强调色。

随后检查 `メトロはこね` 不高亮的问题。实际数据和 path 都存在：从 `大手町` 选中后会生成 `東京メトロ千代田線`、`小田急小田原線`、`小田急箱根鉄道線` 三段真实 path。问题不是缺数据，而是高亮层被改得和底层线路几乎完全同透明度，视觉上看不出来。最终方案是保留“颜色/线宽/几何完全像真实线路”，但 selected overlay 使用更高 opacity，让玩家能明确看到被选中的车次，同时不破坏“高亮必须沿真实线路走”的公理。
